# AI Configuration

This document outlines the configuration for the AI agent working on this project.

## Project Description

This project is a clone of Twitter, focusing on the original 140-character limit for tweets. It will be built with React, TypeScript, and Tailwind CSS.

## Development Process

This project will follow an iterative development process. The AI will work in sprints, with each sprint focusing on a specific set of features. The development process will include the following steps:

1.  **Sprint Planning**: At the beginning of each sprint, the AI will work with the user to define the goals for the sprint and create a list of tasks to be completed.
2.  **Development**: The AI will write code to implement the features for the current sprint.
3.  **Testing**: The AI will write and run tests to ensure that the code is working correctly.
4.  **Deployment**: The AI will deploy the code to a staging environment for testing and review.
5.  **Review and Feedback**: The user will review the changes and provide feedback.
6.  **Iteration**: The AI will incorporate feedback and make changes as needed.

## Communication

*   **Pull Requests**: The AI will create pull requests for all code changes.
*   **Comments**: The AI will use comments in the code to explain the purpose of the code and to ask questions.
*   **Chat**: The AI will use the chat interface to communicate with the user in real-time.

## Code Style

*   **Camel Case**: All variables and function names will be written in camel case.
*   **Snake Case**: All database table and column names will be written in snake case.
*   **Comments**: The AI will add comments to the code to explain complex logic.

## Error Handling

*   **Try/Catch Blocks**: The AI will use try/catch blocks to handle errors in the code.
*   **Logging**: The AI will log all errors to the user's console.

## Deployment

*   **Staging Environment**: The AI will deploy the code to a staging environment for testing and review.
*   **Production Environment**: The AI will deploy the code to a production environment once it has been tested and approved.

## Testing

*   **Unit Tests**: The AI will write unit tests for all new code.
*   **Integration Tests**: The AI will write integration tests to test the interaction between different parts of the application.
*   **End-to-End Tests**: The AI will write end-to-end tests to test the entire application from the user's perspective.
