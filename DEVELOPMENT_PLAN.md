# Development Plan

## Sprint 1: User Authentication

*   **Goal**: Implement user registration and login functionality.
*   **Tasks**:
    *   Create a user model with fields for username, email, and password.
    *   Implement user registration functionality.
    *   Implement user login functionality.
    *   Implement user logout functionality.
    *   Create a protected route that can only be accessed by authenticated users.

## Sprint 2: Tweet Functionality

*   **Goal**: Implement the ability for users to create, view, and delete tweets.
*   **Tasks**:
    *   Create a tweet model with fields for content, author, and timestamp.
    *   Implement the ability for users to create a new tweet.
    *   Implement the ability for users to view a list of all tweets.
    *   Implement the ability for users to view a single tweet.
    *   Implement the ability for users to delete their own tweets.

## Sprint 3: User Profile

*   **Goal**: Implement user profiles.
*   **Tasks**:
    *   Create a user profile page that displays the user's information and tweets.
    *   Implement the ability for users to edit their profile information.
    *   Implement the ability for users to upload a profile picture.

## Sprint 4: Following and Followers

*   **Goal**: Implement the ability for users to follow and unfollow other users.
*   **Tasks**:
    *   Create a followers model to track which users are following which other users.
    *   Implement the ability for users to follow another user.
    *   Implement the ability for users to unfollow another user.
    *   Display a list of users that the current user is following.
    *   Display a list of users that are following the current user.

## Sprint 5: Likes and Retweets

*   **Goal**: Implement the ability for users to like and retweet tweets.
*   **Tasks**:
    *   Create a likes model to track which users have liked which tweets.
    *   Implement the ability for users to like a tweet.
    *   Implement the ability for users to unlike a tweet.
    *   Create a retweets model to track which users have retweeted which tweets.
    *   Implement the ability for users to retweet a tweet.
    *   Implement the ability for users to un-retweet a tweet.
